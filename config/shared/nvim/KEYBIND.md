# 忘れそうなキーバインド

普段あまり使わないキーに絞ったチートシート。全部の一覧と経緯は [KEYMAP_REVIEW.md](./KEYMAP_REVIEW.md) を参照。

leader キーは **Space**。`Space g g` は Space → g → g と順番に押す（同時押しではない）。

## 自分で割り当てたキー

| キー | 動作 |
|---|---|
| `Space g g` | LazyGit |
| `Space u` | undo ツリー（過去の編集履歴を辿れる） |
| `Space x x` | 診断一覧（Trouble） |
| `Space o r` | タスクを実行（overseer） |
| `gJ` | 1 行 ⇔ 複数行を切り替え（引数・配列・テーブルなど） |
| `<C-S-m>` | よく開くファイル（frecency） |
| `<C-S-s>` | カーソル下の単語をプロジェクト全体から grep |
| `<C-.>` | 記号・絵文字を検索して挿入（インサートモードでも使える） |
| `cp{motion}` / `cP` | クリップボードへコピー（範囲 / 行） |
| `cv` / `cV` | クリップボードから貼り付け / 次の行に貼り付け |
| `:PasteImage` | クリップボードの画像を保存して Markdown/MDX に貼る |

## Telescope の中

| キー | 動作 |
|---|---|
| `<C-s>`（挿入） / `s`（ノーマル） | 縦分割で開く |
| `<C-S-s>`（挿入） / `S`（ノーマル） | 横分割で開く |
| ファイルブラウザで `n` / `r` / `m` / `d` | 新規作成 / 名前変更 / 移動 / 削除 |
| ファイルブラウザで `.` | 隠しファイルの表示切り替え |

## LSP

`<C-q>` 以外は Neovim の組み込み。

| キー | 動作 |
|---|---|
| `<C-q>` | ホバー。表示中にもう一度押すとウィンドウ内に入れる |
| `grn` | リネーム |
| `gra` | コードアクション |
| `grr` | 参照一覧 |
| `gri` | 実装へジャンプ |
| `<C-]>` | 定義へジャンプ（戻るのは `<C-o>`。`<C-t>` はターミナルに割り当て済み） |
| `gO` | ファイル内のシンボル一覧 |
| `]d` / `[d` | 次 / 前の診断 |
| `<C-w>d` | カーソル位置の診断を表示 |

## テキストオブジェクト（mini.ai / nvim-surround）

| キー | 動作 |
|---|---|
| `ciq` / `cib` | 一番近いクォート / 括弧の中身を書き換え |
| `daf` | 関数呼び出し `foo(x)` をまるごと削除 |
| `cia` | 引数を 1 つ書き換え |
| `cinq` | 次の文字列の中身を書き換え |
| `ysiw"` | 単語を `"` で囲む |
| `ds"` | `"` の囲みを外す |
| `cs"'` | `"` を `'` に変える |
