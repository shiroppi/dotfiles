# キーマップ棚卸し

忘れていそうなキーマップをまとめたメモ（2026-10 時点、Neovim 0.12）。
`<leader>` は **Space キー**（`init.lua` の `vim.g.mapleader = " "`）。たとえば `<leader>gg` は「Space → g → g」と続けて押す。今の割り当ては `:map <キー>` で、各プラグインの既定マップは `:help` で確認できる。

## 1. 自分で割り当てたキー

### 編集

| キー | モード | 動作 | 定義場所 |
|---|---|---|---|
| `<C-c>` | n / x | コメントのトグル（組み込みの `gcc` / `gc` を呼ぶ） | `lua/core/keymaps.lua` |
| `cp{motion}` | n / x | システムクリップボードへコピー | 同上 |
| `cP` | n | 行をクリップボードへコピー | 同上 |
| `cv` | n / x | クリップボードから貼り付け（x では選択範囲を置き換え） | 同上 |
| `cV` | n | クリップボードの内容を次の行に貼り付け | 同上 |
| `gJ` | n | 引数リストや配列などの 1 行 ⇔ 複数行を切り替え（treesj） | `lua/plugins/lazy.lua` |
| `<leader>u` | n | undo ツリー（undotree） | 同上 |

> `cp` / `cv` は以前 vim-system-copy が担当していたが、`"+` レジスタを使うマップに置き換えた。
> 以前の `cv{motion}`（motion の範囲をクリップボードの内容で置き換える）は単純な貼り付けに変わっている。

### 検索・ファイル（Telescope）

| キー | モード | 動作 |
|---|---|---|
| `<C-f>` | n | 最近開いたファイル（oldfiles） |
| `<C-S-m>` | n | よく開くファイル（frecency） |
| `<C-m>` | n | 現在のファイルのディレクトリでファイルブラウザを開く（WezTerm なら Enter と区別される） |
| `<C-s>` | n | 現在のバッファ内をあいまい検索 |
| `<C-S-s>` | n | カーソル下の単語をプロジェクト全体から grep |
| `<C-.>` | n / i | 記号・絵文字を検索して挿入（telescope-symbols） |

Telescope のピッカー内:

| キー | 動作 |
|---|---|
| `<C-s>`（挿入） / `s`（ノーマル） | 縦分割で開く |
| `<C-S-s>`（挿入） / `S`（ノーマル） | 横分割で開く |

ファイルブラウザ内（ノーマルモード）:

| キー | 動作 |
|---|---|
| `<CR>` | 開く |
| `n` | 新規作成 |
| `m` | 移動 |
| `r` | 名前変更 |
| `d` | 削除 |
| `.` | 隠しファイルの表示切り替え |

### LSP・診断

| キー | モード | 動作 |
|---|---|---|
| `<C-q>` | n | ホバードキュメント（Lspsaga）。ドキュメント表示中にもう一度押すとウィンドウ内に入れる |
| `<leader>xx` | n | 診断一覧（Trouble） |

### ツール

| キー | モード | 動作 |
|---|---|---|
| `<C-t>` | n | フローティングターミナル（toggleterm）。ターミナルのノーマルモードで `q` を押すと閉じる |
| `<leader>gg` | n | LazyGit（Space → g → g） |
| `<leader>or` | n | タスクランナー（overseer）でタスクを実行 |

### コマンド

| コマンド | 動作 |
|---|---|
| `:PasteImage` | クリップボードの画像を保存して Markdown/MDX に貼る（mdxsnap） |
| `:SlimeGreeting` | ぷよぷよスライムのあいさつ |
| `:ConformInfo` | フォーマッターの状態確認 |
| `:Mason` | LSP サーバーやフォーマッターのインストール |

## 2. 最近変えたキー

| キー | 変更内容 |
|---|---|
| `<leader>gg` | LazyGit は `gg` から移した。`gg` は Vim 標準の「ファイル先頭へ移動」に戻っている |
| `<C-m>` | 多くの端末では Enter と区別できないが、WezTerm（CSI u 対応）では区別できるので、そのまま残している。別の端末で Enter がおかしくなったらここを疑う |

## 3. 無効化した LSP キー（Lspsaga）

使っていなかったので `lua/plugins/lazy.lua` の lspsaga の `keys` でコメントアウトしてある。
これらを無効化したことで、下の「Neovim 組み込みの LSP キー」が使えるようになった。

| キー | 以前の動作 |
|---|---|
| `<C-S-q>` / `gp` | 定義をフロートで覗き見 |
| `gd` | 定義・参照の一覧（finder） |
| `gr` | リネーム |
| `ge` | 現在行の診断を表示 |
| `<C-j>` / `]e` / `[e` | 次 / 前の診断へジャンプ（以前は `[e` と `]e` の向きが逆だった） |

## 4. 覚えておくと便利な組み込み・プラグイン既定のキー

### Neovim 組み込みの LSP キー（0.11 以降）

LSP がアタッチされると自動で使える。

| キー | 動作 |
|---|---|
| `K` | ホバー（`<C-q>` の組み込み版） |
| `grn` | リネーム |
| `gra` | コードアクション |
| `grr` | 参照一覧 |
| `gri` | 実装へジャンプ |
| `grt` | 型定義へジャンプ |
| `gO` | ドキュメント内のシンボル一覧 |
| `<C-s>`（挿入） | シグネチャヘルプ |
| `]d` / `[d` | 次 / 前の診断 |
| `]D` / `[D` | 最後 / 最初の診断 |
| `<C-w>d` | カーソル位置の診断をフロート表示 |
| `<C-]>` | 定義へジャンプ（LSP の tagfunc 経由） |

### コメント（組み込み）

| キー | 動作 |
|---|---|
| `gcc` | 行のコメントをトグル |
| `gc{motion}` | 範囲をトグル（例: `gcap` で段落） |
| `gc`（ビジュアル） | 選択範囲をトグル |

### nvim-surround

| キー | 例 | 動作 |
|---|---|---|
| `ys{motion}{char}` | `ysiw"` | 単語を `"` で囲む |
| `yss{char}` | `yss)` | 行全体を囲む |
| `ds{char}` | `ds"` | `"` の囲みを外す |
| `cs{old}{new}` | `cs"'` | `"` を `'` に変える |
| `S{char}`（ビジュアル） |  | 選択範囲を囲む |
| `t`（タグ） | `ysiwt` → `div<CR>` | `<div>` タグで囲む |

### mini.ai（`a` / `i` のテキストオブジェクト拡張）

`d` / `c` / `y` / `v` の後に続けて使う。

| オブジェクト | 対象 |
|---|---|
| `b` | 括弧 `()` `[]` `{}` のどれか（例: `cib`） |
| `q` | 引用符 `"` `'` `` ` `` のどれか（例: `ciq`） |
| `f` | 関数呼び出し（例: `daf` で `foo(x)` ごと削除） |
| `a` | 関数の引数（例: `cia` で引数 1 つを書き換え） |
| `t` | HTML タグ |
| `?` | 対象の左右の文字を毎回入力して指定 |
| `n` / `l` を挟む | 次 / 前の対象（例: `cinq` で次の文字列の中身を変更） |

### 補完（nvim-cmp）

| キー | 動作 |
|---|---|
| `<C-Space>` | 補完を手動で開く |
| `<Tab>` / `<S-Tab>` | 候補の選択。補完が出ていないときはスニペットの次 / 前のプレースホルダーへ |
| `<CR>` | 確定 |
| `<C-e>` | 補完を閉じる |
| `<C-d>` / `<C-f>` | ドキュメントのスクロール |

### その他

| キー | 動作 |
|---|---|
| `gx` | カーソル下の URL を開く（組み込み） |
| `]q` / `[q` | quickfix の次 / 前（組み込み） |
| `]b` / `[b` | 次 / 前のバッファ（組み込み） |
| `:Gitsigns` | gitsigns の操作（既定のキーマップは無い。例: `:Gitsigns preview_hunk`、`:Gitsigns blame_line`） |

## 5. 端末によっては届かないキー

以下のキーは CSI u などの拡張キー入力に対応した端末（WezTerm、kitty、Ghostty など）でないと Neovim まで届かない。
普段使いの WezTerm では動いているので、別の端末を使うときだけ気にすればよい。

- `<C-m>`（Enter と区別できない）
- `<C-S-s>`、`<C-S-m>`
- `<C-.>`

## 6. 標準の動作を上書きしているキー

| キー | 上書き前の動作 |
|---|---|
| `<C-f>` | 1 画面下へスクロール（`<C-d>` を 2 回押すか、`<PageDown>` で代用できる） |
| `<C-t>` | タグスタックを戻る（LSP で定義ジャンプした後に戻る操作にも使われる。代わりに `<C-o>` で戻れる） |
| `<C-m>` | Enter と同じ（WezTerm 以外の端末の場合） |
